## О проекте

**«Новое поколение»** — проект создаваемой молодёжной организации и открытой платформы для инициатив, развития, наставничества и практических действий.

В основе проекта — простой маршрут:

> **Быть услышанным → Говорить → Делать**

Цель проекта — создать понятную среду, в которой молодой человек сможет предложить идею, найти команду, получить поддержку и довести инициативу до конкретного результата.

## Статус проекта

> **Организация находится на этапе формирования.**

Сейчас формируются команда, структура направлений, первые инициативы, партнёрские связи и будущие форматы работы.

Сайт используется как публичная точка входа в проект: здесь можно познакомиться с концепцией, направлениями и предложить свою идею.

## Технологии

Проект намеренно сделан лёгким и независимым от тяжёлых фреймворков:

- HTML5;
- CSS3;
- Vanilla JavaScript;
- локальные шрифты и графика;
- GitHub Actions;
- GitHub Pages.

Для запуска сайта не требуются `npm install`, Node.js или отдельный build-step.

## Локальный запуск

Из корня репозитория:

```bash
python3 -m http.server 8000 --directory site
```

После запуска:

```text
http://localhost:8000/
```

## Публикация на GitHub Pages

Проект публикуется из папки `site/` через GitHub Actions.

Workflow:

```text
.github/workflows/pages.yml
```

После изменений достаточно сделать commit в ветку `main` и дождаться успешного деплоя во вкладке **Actions**.

Публичная версия:
